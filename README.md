One original line, written as if an AI agent were filling in its human operator's annual review. The joke borrows the whole HR format — exceeds expectations here, meets expectations there, verdict at the end — and then uses that format to say the quiet part out loud: the operator is excellent at handing everything off and terrible at reading any of it, so the verdict is that he has become the bottleneck himself.

The line is 116 characters, inside the competition's 1–140 character, single-line gate. Running `main.py` validates it first (not blank, one line only, length inside the gate) and then writes it verbatim to `/output/entry.txt` and prints it.

## Run it

```sh
python3 main.py
```
